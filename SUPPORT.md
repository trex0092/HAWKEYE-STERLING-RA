# Support

Thanks for using **Hawkeye Sterling — Entity Risk Assessment (RA)**. This page
explains where to get help and how to get the fastest, most useful answer.

## Documentation first

Most questions are answered in the project docs:

- **[README](README.md)** — features, risk methodology, setup, tests, and
  project structure.
- **[Regulatory Watch](docs/regulatory-watch.md)** — how the automated
  regulatory-source monitoring works and how to configure it.
- **[Governance docs](docs/governance/)** — ISO 42001 SoA, NIST AI RMF
  crosswalk, DPIA, AI Acceptable-Use Policy, AI Asset Register, Incident
  Runbook, and the gap analysis.
- **Live app:** <https://hawkeye-sterling-ra.netlify.app>

## Getting help

| I want to… | Do this |
|---|---|
| Report a bug | Open a **Bug report** issue → [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) |
| Request a feature | Open a **Feature request** issue |
| Flag a regulatory / sanctions / FATF change or risk-data review | Open a **Compliance review** issue |
| Report a security vulnerability | **Do not open a public issue** — follow [`SECURITY.md`](SECURITY.md) |
| Ask how to contribute | Read [`CONTRIBUTING.md`](CONTRIBUTING.md) |

## Before you open an issue

- Search [existing issues](https://github.com/trex0092/HAWKEYE-STERLING-RA/issues)
  to avoid duplicates.
- Include your browser and version, the page (`index.html` / `console.html` /
  `advisor.html`), steps to reproduce, and what you expected.
- Never paste API tokens, customer data, or other secrets into an issue.

## Scope of support

This is an internal compliance tool provided "as is" (see [`LICENSE`](LICENSE)).
Support is best-effort and covers the application and its automation. It does
**not** constitute legal or regulatory advice — the tool supports, and does not
replace, professional judgement, firm policy, and applicable AML/CFT
obligations.
