# Model Card — Adverse-Media Classifier

*Card date: 2 Jul 2026 · Revised: 28 Jul 2026 (accuracy-hardening programme — description scanning, keyword tiers, gated repeat counter; card also corrected for the Bing News feed added 25 Jul) · Type: **deterministic keyword/typology classifier** over three news feeds + a bulk watchlist net (optional LLM triage — see [`ai-triage.md`](ai-triage.md)) · `screen.py`, `adverse-media.mjs`*

| Field | Detail |
|---|---|
| **Purpose** | Surface negative news linking a customer/UBO to financial crime, and bucket it by typology, so the MLRO can assess adverse-media risk (FATF R.10 risk-based EDD). |
| **Business owner** | MLRO. |
| **Technical owner** | Compliance Engineering. |
| **Inputs** | Subject name → three independent free feeds plus a bulk net: **Google News RSS** (worldwide locale matrix, default **8** of 76 editions swept — `ADVERSE_LOCALES`), **GDELT DOC 2.0** (100+ languages, machine-translated), **Bing News RSS** (third net, added 25 Jul 2026), and the OpenSanctions crime-topic watchlist (~290k names, screened through the sanctions matcher). **Headlines AND feed descriptions/snippets** (tag-stripped, bounded) matched against the English red-flag stems + curated sets across 30+ languages incl. **Arabic** (all mapped to English canonicals for uniform typology bucketing). |
| **Outputs** | Ranked (flagged-first, then **source-credibility tier** from `data/source-credibility.json` — annotation/ordering only, never a gate — then recency), duplicate-collapsed articles: title, source, snippet, date, URL, matched keywords, **keyword tier (strong/weak)**, typology categories; a per-subject flagged/clear verdict; a committed evidence log (`data/adverse-media-evidence.json`, 400-day retention) whose entries carry tier, name-relevance, corroborating outlets and a **canonical-URL story fingerprint**; a **repeat-pattern** signal (≥3 distinct stories / 90 days → EDD + STR assessment) that counts **distinct fingerprints among counter-eligible entries only**: relevance HIGH/MEDIUM (or UNSCORABLE cross-script — non-Latin press is never excluded by a Latin token-overlap test), and strong keyword tier or a second independent outlet for weak-tier stories. **Nothing is ever unflagged or dropped** — eligibility gates escalation weight only; exclusions are logged per run. Per-subject cap `ADVERSE_MAX_RESULTS` (default 8, was a hard-coded 5). |
| **Knowledge / training source** | None trained — a curated keyword→typology map (`KEYWORD_TYPOLOGY`) maintained under the quarterly review; live news feeds. |
| **Prompt strategy** | N/A for the classifier. Optional LLM relevance triage is a separate, gated component ([`ai-triage.md`](ai-triage.md)). |
| **Limitations** | News is real-time but false-positive-prone; keyword matching can over- or under-flag (weak-tier gating reduces the escalation cost of generic terms — "political", "lawsuit", "ESG" — without unflagging them); media alone is never conclusive — current status must be confirmed before any adverse decision; free feeds lack the curation/SLA of commercial providers; GDELT items carry no description, so description-scanning recall applies to the RSS feeds only; wrong-subject stories whose headline carries the subject's full name remain indistinguishable at headline level (the relevance gate catches partial-name collisions only). |
| **Known risks** | **Missed adverse story** (recall) — mitigated by three independent feeds + the watchlist net, Arabic coverage, description scanning, and the **sustained-degradation escalation** (>25% of subjects losing their pass across 3 runs → Anomaly Watch opens an MLRO issue; "silence is never evidence"). **Manufactured escalation** (precision) — a same-surname wrong-subject flood, a syndicated re-serve under rotating tracking params, or a run of generic-keyword headlines used to reach the ≥3-story signal on their own; closed by the relevance/tier/fingerprint counter gates (28 Jul 2026), with legacy evidence entries kept counter-eligible (no retroactive suppression). Prompt-injection via a hostile headline is detected and the model is *not* invoked (deterministic classification). Risk register R-06. |
| **Bias assessment** | Language coverage explicitly includes Arabic and Turkish locales so non-English-press subjects are not systematically under-screened; keyword set reviewed quarterly for balanced typology coverage. |
| **Human oversight** | Every finding is raw evidence with a link; the MLRO decides (no action / investigate / escalate / file STR). |
| **Monitoring** | `test/adverse-media.test.mjs`, engine tests (GDELT parse, Arabic mapping, evidence log, repeat/degradation) every push/PR; quarterly methodology-review task (`quarterly-review.yml`); daily run log. |
| **Performance metrics** | **Labelled accuracy benchmark, CI-floored** ([`../governance/screening-accuracy-benchmark.md`](../governance/screening-accuracy-benchmark.md)): adverse classification accuracy **100%** (114/114 py; 88/88 js) vs the frozen pre-hardening baseline of 57.9% (py) / 77.3% (js); repeat-signal accuracy **100%** (6/6 multi-day scenarios) vs 50% baseline. Feed coverage; duplicate-story collapse ratio; evidence-log completeness; repeat-pattern precision reviewed quarterly. Benchmark-relative — outcome data runs through the backtesting protocol. |
| **Retirement criteria** | Replace/augment when a commercial adverse-media feed is adopted; the keyword methodology and feeds would be re-validated. |
