# Management Review (AIMS 9.3) — Template & Log

The AIMS is reviewed by senior management/MLRO at planned intervals (at least
annually) and after material change. Use this template per review; keep the log.

## Review inputs (agenda)
1. Status of actions from the previous review.
2. Changes to context / interested parties / regulation (UAE, FATF, PDPL, AI Act).
3. Performance: screening coverage, alert volumes, false-positive rate, run times,
   `screening-metrics`, freshness-check results.
4. AI risk register changes (new/changed residual risks).
5. Nonconformities & corrective actions (`corrective-actions.md`).
6. Audit results (QA-gate outcomes, CI status, internal/external audit).
7. Third-party / DPA changes (`third-party-register.md`).
8. Bias/fairness, security (prompt-injection blocks), incidents.
9. Adequacy of resources & competencies.
10. Opportunities for improvement.

## Review outputs (record)
- Decisions on improvements, resource changes, residual-risk acceptance.
- New actions (owner + due date).
- Confirmation the AIMS remains suitable, adequate, and effective.
